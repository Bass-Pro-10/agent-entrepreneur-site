Privacy Policy

Last updated: November 16, 2026

The Agent Entrepreneur ("we") operates the YouTube channel @AgentEntrepreneur and the internal software ("Agent Entrepreneur Studio") used to produce and publish its videos.

What the software does

Agent Entrepreneur Studio is a private, single-user tool. It uses the YouTube Data API solely to upload videos, set thumbnails, schedule publication, and read statistics for our own channel.

Data we access

Through Google OAuth we access only our own YouTube channel data (video metadata, upload status, and view counts). We do not access, collect, or store any data from other users or viewers.

Data we store

OAuth tokens for our own channel are stored privately by the channel owner. No viewer data is collected by this website, which sets no cookies and runs no analytics.

Sharing

We do not sell, share, or transfer any Google user data to third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
